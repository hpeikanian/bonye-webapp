# bonYe! وب‌اپ مشتریان

این پروژه پوشه، ریپوزیتوری، تنظیمات انتشار و خروجی مستقل دارد. API و حساب مشتریان با اپ اندروید مشترک است.

## وضعیت

ساختار اولیه آماده است؛ وب‌اپ قابل نصب هنوز پیاده‌سازی و آزمایش نشده است. ریپوزیتوری گیت‌هاب مقصد: `hpeikanian/bonye-webapp`؛ ایجاد آن از محیط فعلی با Forbidden مسدود شد.

## توسعه هماهنگ

کد قابلیت‌ها، ترجمه‌ها، مدل‌ها و ارتباط API باید از یک منبع مشترک Flutter استفاده شود؛ از نگهداری دو کپی مستقل کد جلوگیری شود. پروژه اندروید فعلی منبع شروع استخراج بسته مشترک است. هر پروژه پوسته و تنظیمات مخصوص پلتفرم خود را نگه می‌دارد و نسخه یکسان بسته مشترک را مصرف می‌کند.

هر تغییر قابلیت باید برای اندروید و وب بررسی شود. ادعای آماده بودن هر دو نسخه تنها پس از موفقیت بررسی‌های هر دو هدف مجاز است. تغییرات مخصوص یک پلتفرم باید صریحاً در یادداشت انتشار مشخص شوند.

## پیش‌نیازهای وب

پیش از استفاده از کد فعلی، دانلود پادکست و ذخیره فایل (کدهای dart:io)، ذخیره توکن، پخش پس‌زمینه و پیکربندی صوت باید برای وب سازگار شوند. API باید CORS برای دامنه واقعی وب‌اپ داشته باشد. نشست‌ها و اطلاعات خصوصی نباید در کش آفلاین عمومی ذخیره شوند. نصب و رفتار صوت روی Safari آیفون باید آزمایش شود.

## اتصال به گیت‌هاب

پس از ایجاد ریپوزیتوری خالی و خصوصی `bonye-webapp` در حساب hpeikanian و افزودن آن به دسترسی محیط:

```sh
cd /workspace/bonye-webapp
git push -u origin main
```
