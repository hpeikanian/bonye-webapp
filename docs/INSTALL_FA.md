# نصب وب‌اپ بنیه روی هاست

فایل `downloads/bonye-webapp-v0.2.2.zip` خروجی آماده برای مسیر `/app/` است؛ سورس برای نصب لازم نیست.

1. در File Manager هاست، کنار فایل‌های سایت در document root (معمولاً public_html)، پوشه‌ای به نام `app` ایجاد کنید.
2. ZIP را داخل همین پوشه آپلود و استخراج کنید. `index.html` باید مستقیماً داخل `public_html/app/` باشد؛ پوشه تو در تو نسازید. فایل مخفی `.htaccess` نیز همراه خروجی است.
3. آدرس `https://bonye.pet/app/` را باز کنید. نام و لوگو باید bonYe! باشد و فارسی/انگلیسی قابل انتخاب باشد.
4. ورود با حساب واقعی، نمایش موجودی محصول و باز شدن خرید را بررسی کنید. اطلاعات از API فعلی بنیه خوانده می‌شود؛ دیتابیس جدیدی نصب نکنید.
5. در Safari آیفون Share → Add to Home Screen را انتخاب کنید و از آیکن ایجادشده دوباره باز کنید.

این بسته روی هاست از طرف ما نصب نشده است. تست حساب واقعی، پرداخت و آیفون واقعی هنوز باقی است. فایل‌های WordPress و پوشه totalsystem را تغییر ندهید؛ فقط پوشه app محل نصب است.

## بروزرسانی

خروجی جدید را در همین مسیر منتشر کنید. فایل‌های index.html، flutter_bootstrap.js، manifest.json و sw.js نباید در کش بلندمدت هاست یا CDN بمانند. ابتدا همه فایل‌های خروجی و در انتها sw.js را جایگزین کنید. فایل‌های قدیمی موتور و assets را تا پایان مهاجرت کاربران حفظ کنید. کاربران تب‌های قدیمی را ببندند و وب‌اپ را دوباره باز کنند؛ حذف و نصب مجدد معمولاً لازم نیست. انتشار همزمان نسخه اندروید و وب نیازمند روند انتشار هاست و APK است؛ CI فعلاً فقط خروجی مشترک تولید می‌کند.

## بررسی محیط توسعه

`tool/build_web.sh` خروجی را با lockfile و نسخه Flutter مشخص تولید می‌کند. تست مرورگر Cache Storage:

```sh
CHROME_EXECUTABLE=/usr/bin/chromium flutter test test/podcast_cache_browser.dart --platform chrome
```

برای smoke مرورگر، Python و Playwright لازم است. خروجی را در مسیر `/app/` یک HTTP server داخلی سرو کنید، سپس `python3 tool/smoke_browser.py --base-url http://127.0.0.1:8765/app/` را اجرا کنید. این تست پاسخ API را شبیه‌سازی می‌کند و هیچ ورود یا خرید واقعی انجام نمی‌دهد. آدرس localhost برای کاربران لینک نصب نیست.

## خطای ۴۰۳

بسته اولیه مجوز فایل 0600 داشت؛ بسته fixed فایل‌ها را با 0644 منتشر می‌کند. پس از استخراج، پوشه app و زیرپوشه‌ها باید 0755 و فایل‌ها (از جمله .htaccess) باید 0644 باشند. مجوز 0777 لازم نیست. اگر index.html با مجوز صحیح هنوز 403 داد، Error Log هاست و قوانین دسترسی .htaccess ریشه باید بررسی شوند؛ آن فایل‌ها را بدون بررسی حذف نکنید.
